## 🚀 Featured Projects

### 🧑‍💻 AI Codebase Assistant (RAG)

Ask questions about any GitHub repository and get answers with **line-level citations**.

* AST-based code chunking with `tree-sitter`, embeddings via `text-embedding-3-small`, per-repository collections in ChromaDB
* **Hybrid search (vector + BM25)** to reduce hallucinations in GPT-4o-mini answers
* Streamlit chat interface with conversation memory

`Python` · `LangChain` · `OpenAI API` · `ChromaDB` · `Streamlit`

### 🏠 Property Search & Decision Agent (Multi-Agent AI)

A **LangGraph system of 11 agents** (4 running in parallel) analysing 5,300+ Delhi rental listings.

* Risk and Ranking agents score properties on commute distance, price deviation and verification score, then pick the top 5
* **Human-in-the-loop** approval/override via LangGraph interrupt, re-running only 4 of 11 agents and saving ~63% of compute vs a full run

`Python` · `LangGraph` · `OpenAI API` · `Streamlit`

### 🛵 Swiggy Delivery Time Prediction

End-to-end **XGBoost regression** model on 45,500+ records.

* **R² = 0.821**, **MAE = 3.17 minutes**
* Compared 5 regression models; randomized search with 5-fold CV lifted R² from 0.814 to 0.821
* Feature engineering on distance, traffic, weather, ratings and time, with a full preprocessing pipeline

`Python` · `Scikit-learn` · `XGBoost` · `Pandas` · `NumPy`

### 💬 Product Reviews Sentiment Analysis

**Bidirectional LSTM** classifier with pre-trained Word2Vec embeddings on 205,000+ reviews.

* Positive / Neutral / Negative classification with **92.59% test accuracy**
* Streamlit app for real-time predictions with per-class probabilities

`Python` · `TensorFlow` · `Keras` · `NLP` · `Word2Vec` · `Streamlit`
